# ExaGoal Control Hub — Chrome Extension (Manifest V3)

A lightweight browser popup extension mirroring the **Control Hub (Challenge #357)**.

## Features
- **4 Difficulty Presets**: Foundational (10% Hard), Standard (20% Hard), Advanced (35% Hard), Mastery (60% Hard).
- **Auto-balancing Sliders**: Adjust Easy / Medium / Hard % dynamically summing to 100%.
- **Bloom's Cognitive Taxonomy**: Quick-toggle multi-select chips.
- **Question Type Distribution**: Overview of Subjective, Numerical, and MCQ split.
- **Instant Sync Feedback**: Visual confirmation upon saving parameters.

## How to Load in Google Chrome:
1. Open Google Chrome and go to `chrome://extensions/`.
2. Turn ON **Developer mode** (top right toggle).
3. Click **Load unpacked** (top left button).
4. Select this directory:
   `C:\Users\Jayesh\OneDrive\Desktop\FarAway\ExaGoal v3.0\chrome-extension`
5. Click the puzzle icon in Chrome toolbar and pin **ExaGoal Control Hub**!
